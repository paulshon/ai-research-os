# LLB 데이터분석 대시보드 (A~L)

화면: `/llb/analytics` · 코드: `apps/web/components/literature/llb-dashboard.tsx`, 차트 부품 `viz.tsx`
서버: `GET /api/scholar/dashboard?q=…&section=<영역>` → `lib/literature/llb-dashboard.ts` · 계산 부품 `text-analytics.ts`

> ## ⚠ JCR 지표 범위 안내
> JCR 지표(JIF·사분위·JCI·아이겐팩터 등)는 **학술지 논문의 약 31%에만** 있습니다. 값이 있는 논문까지만 저널 지표 분석에 쓰이며, **학술대회 논문·학위논문은 저널 지표 분석에서 빠집니다.** 편수·출판사·색인 DB·국가·주제·인용 분석은 전체 논문을 씁니다. 화면(상단 안내, C·I 영역)에는 해당 검색 결과의 실제 보유 비율을 함께 표시합니다.

검색에 일치한 논문 집합은 **검색 화면과 같은 기준**(관련도 정렬은 제목 일치 단계)입니다. 큰 집합은 SQL 로 직접 집계하고, 논문 단위 계산이 필요한 텍스트·네트워크 분석은 순위 상위 표본(최대 4,000편)을 씁니다. 같은 검색의 결과는 서버 메모리에 5분 캐시합니다.

## F 영역 계산 방식(정밀 분석)
- **주제 변천(샌키)**: 순위 상위 최대 4,000편을 연도 4구간(편수 균등)으로 나누고, 구간마다 키워드 동시출현 네트워크의 Louvain 군집을 만든다. 이웃 구간 군집은 구성원 Jaccard ≥ 0.08(또는 작은 쪽의 50% 이상 포함)이면 잇는다. 이어지지 않는 앞 구간 군집은 ‘소멸’, 뒤 구간 군집은 ‘신규’, 하나가 여럿으로 이어지면 ‘분기’, 여럿이 하나로 이어지면 ‘합류’.
- **학제성(Rao–Stirling)**: 논문마다 OpenAlex 개념 집합 → 개념 간 거리 d = 1 − (동시출현/√(빈도·빈도)) → RS = Σ_{i≠j} p_i p_j d_ij (p 는 균등). 분야 간 유사도 히트맵은 분야별 개념 빈도 벡터의 코사인.
- **토픽·초록 지도**: 제목(×2 가중)+초록 → 토큰화(영문 불용어·한글 어절 처리) → TF-IDF(문서빈도 3 이상·40% 이하, 어휘 4,000) → 무작위 부분공간 반복법으로 잠재 의미(LSA) 14차원 → k-means(k-means++, 코사인) → 상위 2개 주성분으로 배치. 군집 이름 = 군집 평균 TF-IDF 가 다른 군집보다 높은 단어. (임베딩 신경망 모델이 아닌 통계 기반 근사)
- **연구 공백 매트릭스**: 상위 주제 18개 × 연구 방법 9종·연구 대상 7종의 사전(`text-analytics.ts` 의 `METHODS`, `OBJECTS`)을 제목+초록에서 검색해 건수를 센다. 기대 = 주제 편수 × 열 점유율, 관측/기대 < 0.4 이고 기대 ≥ 4 인 칸을 공백 후보로 표시. 일치 집합이 15만 편을 넘으면 해시 표본.

## 제약
- 읽기 전용 계정 `llb_ro`: 결과 행 ≤ 100,000, 질의 ≤ 120초 — 모든 질의가 이 안에서 동작한다. `topic_*` 와 `citation` 은 처음 호출에 1분 안팎 걸릴 수 있다.
- 방법·대상 사전은 단어 일치 기반이라 표기 차이로 누락될 수 있다. 회귀는 상관이며 인과가 아니다.

## 종단·횡단 분석
- **종단(K)**: 같은 대상을 시간 순서로 따라간다. 올해(집계 중)는 제외하고 편수가 20편 이상인 해부터의 완결 연도만 쓴다. 성장 모형은 선형·지수(로그 선형)·로지스틱(포화 수준 K 격자 탐색)을 모두 적합해 AIC 가 가장 작은 모형으로 3년을 예측하고, 변화점은 로그 편수의 평균 이동을 이진 분할(벌점 2σ²lnn)로 찾는다. 추세 검정은 Mann–Kendall(동점 보정), 기울기는 Sen. 주제 생애주기는 **전체 편수 대비 점유율**의 최근 5년 대 이전 5년 증감으로 신흥·성장·성숙·쇠퇴·정체를 가른다(전체가 빠르게 크는 분야에서 모두 ‘신흥’이 되는 것을 막는다).
- **횡단(L)**: 기준 연도 한 해로 한정해 논문 나이를 같게 맞춘 뒤 비교한다. 기준 연도는 화면에서 고르며(기본 2024) `refYear` 로 전달한다. 교차표는 χ² 독립성 검정, 집단 비교는 log(1+피인용)의 Welch t 검정과 Cohen d, 분산분석은 분야·유형별 η²(Cohen 기준 0.01/0.06/0.14).
- 통계 부품은 `lib/literature/panel-stats.ts`(분포 함수는 알려진 값 χ²(1)=3.841→0.05, F(2,30)=3.316→0.05, t(30)=2.042→0.05 로 검증).

## 시각화
선·스택·스트림·막대·**롤리팝**·히트맵·산점도·트리맵·선버스트·샌키·UpSet·타일 지도·코드·포레스트·로렌츠·상자·흐름도·PRISMA 흐름 + **도넛·레이더·범프·슬로프·와플·게이지·소형 다중 선·예측 밴드·사분면**. 값이 없는 해는 선을 0 으로 떨어뜨리지 않고 건너뛴다.

## v3.4 추가 기능
- **A~L 한 번에 보기**: 상단 ‘A~L 한 번에 보기’를 고르면 16개 호출(영역 12개 + F 하위 5개 중 중복 제외)을 가벼운 것은 둘씩, 텍스트·인용망(주제 변천·학제성·토픽 지도·인용 구조)은 뒤에서 하나씩 차례로 불러 한 화면에 영역 머리글과 함께 채웁니다. 시간 초과·5xx 는 한 번 다시 시도하며, 같은 영역을 두 번 요청하지 않습니다. 진행은 도넛 로더(영역별 조각)로 표시합니다.
- **내보내기**: 그림이 있는 모든 차트 카드 오른쪽 위의 PNG·JPG 단추(2배 해상도, 제목 띠 포함). 네트워크 화면은 PNG·JPEG·SVG.
- **색상 모드·스타일 옵션**: 차트 색상 모드 7종(기본·선명·색각 이상 친화 Okabe-Ito·따뜻·차가운·자연·단색). 네트워크 화면은 추가로 배경(청록·어두운 색·흰색·미색), 노드 크기 배율, 선 굵기·투명도·색(배경에 맞춤/연결 노드 색/금색/회색), 글자 크기, 초기화.
- **해석 도움말**: 모든 차트 아래 ‘쉬운 해석’과 ‘학술적 해석’ 두 탭(`lib/literature/guides.ts`, 제목 부분 일치). 네트워크 8개 탭 각각의 해설도 같은 방식.
- **글자 크기 통일**: 카드 폭이 달라도 차트 안 글자가 화면에서 11~12.5px 로 보이도록 보정(큰 숫자 글자는 14~24px). 롤리팝은 실제 폭 기준으로 그립니다.
- **종단 정밀화**: 최근 3년 감추고 예측 검증(MAPE·RMSE, 선형·지수·로지스틱·Holt·단순 지속), Holt 감쇠 추세 예측, Pettitt 변화점 검정, 자기상관 보정 Mann–Kendall(TFPW), 잔차 자기상관·Durbin–Watson, 전년 대비 증감률 95% 구간, 저자 활동 지속 Kaplan–Meier(첫 등장 시기 3구간).
- **횡단 정밀화**: Holm 다중비교 보정 p, Hedges g 와 95% 구간, 분야·유형 Kruskal–Wallis(ε²) 비모수 확인, 분야별 25·50·75·90% 분위수, **반복 횡단**(2005년~ 해마다 같은 비교를 되풀이해 효과 크기 g 의 추이를 봄, log FWCI 로 논문 나이 보정).
- **로딩 표시**: LLB 하위 메뉴(검색·네트워크·분석·인사이트·공백·설계·군집)와 문헌연구 엔진의 공백·설계·군집 분석 로딩에 기존 도넛 로더를 공통 적용.
