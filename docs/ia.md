# Information Architecture — 두 트랙

두 트랙은 **분리 운영**한다. 디자인 토큰·컴포넌트는 공유하고, 강조색만 다르다.

## 연구자 트랙 (강조색 `#6d8dff`)

| 그룹 | 메뉴 | 한 줄 역할 |
|---|---|---|
| 현재 상황 | 연구 대시보드 | 다음에 할 일 하나와 진행 상태를 본다 |
| | 논문 일정 | 마감과 마일스톤을 관리한다 |
| 1 연구 설계 | 연구 설계 | 주제·RQ·가설을 확정한다 |
| | 연구 방법 | 방법 유형과 표본·도구를 설계한다 |
| | 논문유형구조 | 34개 유형별 장 구조를 참조한다 |
| 2 자료 수집 | 문헌 연구 | 문헌을 찾고 갭을 본다 |
| | 참고문헌 | 본문 인용과 목록을 대조한다 |
| | 문장 라이브러리 | 재사용 문장과 변수 슬롯을 모은다 |
| 3 집필 | 논문 작성 | 절 단위로 원고를 쓴다 |
| 4 검증 | 논문 분석 | **수치** — 내 논문은 지금 몇 점인가 |
| | 검토·검증 | **규정** — 규정에 걸리는 곳은 어디인가 |
| | 논문 크리틱 | **표현·내용** — 문장과 주장이 설득력 있는가 |

### 검증 3메뉴의 경계

- **논문유형구조** = 규범 (이 유형의 논문은 어떻게 생겼는가)
- **논문 분석** = 수치 (섹션×축 점수·백분위)
- **검토·검증** = 규정 (형식 규정 위반)
- **논문 크리틱 · 교정** = 표현 (맞춤법·문체)
- **논문 크리틱 · 비평** = 내용 (주장의 설득력)

## 연구준비자 트랙 · RDOS (강조색 `#3ecfb2`)

| 그룹 | 메뉴 | 한 줄 역할 |
|---|---|---|
| 나의 학습 | 학습 대시보드 | 오늘의 한 가지와 6축 진행 |
| | 성장 로드맵 | "할 수 있게 되는 일"로 정의된 레벨 |
| 1 기초 이해 | 연구 기초 · 연구설계 기초 · 연구방법론 기초 | 동일 CourseLayout |
| 2 실습 훈련 | 논문 읽기 · 구조 · 글쓰기 · APA | 사용자가 하고 AI 는 검토만 |
| 3 상시 지원 | AI 튜터 · 지식 코어 | 맥락 인지 · 배운 용어 누적 |
| 4 인증 | 연구 준비자 인증 | 요건 6개 공개 · 연구자 트랙 선행 |

이 트랙의 AI 는 **대신 쓰지 않는다.**
